# Statutes of California (1959) — ACR No. 29 / Resolution Chapter 48

Open verification package for the History prompt (Short Hills, New Jersey daughter in the Hardy memorial transmission clause).

## Why this package exists

The official Volume 2 chapters PDF (`59Vol2_Chapters.pdf`, ~143 MB, 2,812 pages) is a 1999 linearized PixEdit/Acrobat scan. Some **in-browser** PDF viewers mis-read the linearization hints and appear to show only a few pages. Desktop readers (and libraries such as QPDF / PyMuPDF / pypdf) open all 2,812 pages correctly.

**Do not use GitHub-hosted extracts or Wayback snapshots of GitHub raw URLs for verification.** The Golden Trajectory uses only the California Assembly Chief Clerk originals (plus an optional Wayback `id_` raw mirror of that same official PDF).

### How to open the Vol. 2 clause pages

1. Download the official Chief Clerk PDF (or the Wayback `id_` raw mirror of that same URL).
2. Open it in a desktop PDF reader (not a broken in-browser linearization preview).
3. Go to **PDF page 2462** (= printed page **5484**). PDF page 2461 = printed 5483 (start of ACR 29 / Ch. 48).
